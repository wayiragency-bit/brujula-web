# Brújula Web

Frontend independiente de Brújula, construido con Next.js 14, App Router y Tailwind CSS.

## Desarrollo local

1. Copia `.env.example` como `.env.local`.
2. Instala dependencias con `pnpm install`.
3. Inicia el frontend con `pnpm dev`.

La aplicación estará disponible en `http://localhost:3000`.
